# Contributing to Product & Inventory Management System

First off, thank you for considering contributing to this project! 🎉

## 📜 Code of Conduct

Please be respectful, open, and welcoming in all interactions across the community and issues.

## 🛠️ How Can I Contribute?

### Reporting Bugs
- Search existing issues to verify if the bug has already been reported.
- If not, create a new issue using the **Bug Report** template.
- Include a clear description, reproduction steps, expected behavior, and screenshots/console logs where applicable.

### Suggesting Enhancements
- Check the issue tracker to see if a similar suggestion is already under discussion.
- Open an issue using the **Feature Request** template.
- Clearly describe the use case, why this feature would be valuable, and proposed implementation ideas.

### Pull Requests
1. **Fork the repository** to your own GitHub account.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/your-username/product-management-system.git
   ```
3. **Create a topic branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Install dependencies and test your changes**:
   ```bash
   npm install
   cd client && npm run build
   ```
5. **Commit your changes** with clear and descriptive commit messages (following conventional commits if possible, e.g., `feat: add export to excel`, `fix: warehouse transfer validation`).
6. **Push to your branch**:
   ```bash
   git push origin feature/my-new-feature
   ```
7. **Submit a Pull Request** against the `main` branch with the provided PR template filled out.

---

Thank you for helping make this project better!
